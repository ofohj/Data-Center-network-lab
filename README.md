# Data-Center-network-lab
데이터센터 환경을 가정한 Leaf-Spine 기반 네트워크 아키텍처 구성에 대한 프로젝트를 기록한 공간입니다.

---
## 🏢 프로젝트 소개
### 1. 개요
데이터센터에서 왜 Leaf-Spine 구조를 쓰는지 파악하기 위해, 전통적인 3-Tier 아키텍처에서 Leaf-Spine으로 확장되는 방향으로 프로젝트를 계획했습니다.

### 2. 확보하고자 하는 역량
- 데이터센터 환경에 적합한 네트워크 아키텍처 설계 및 구축 역량
- L2/L3 계층별 역할 이해 및 네트워크 설정, 운영 역량
- 네트워크 운영 중 발생하는 장애 분석 및 해결 역량

---
## 🏢 주요 실습 내용
| 주차 | 작업명 |
| --- | --- |
| 1주차 | 네트워크 구조 파악 및 설계 |
| 2주차 | VLAN 및 L2 스위치 구성 |
| 3주차 | 정적 및 동적 라우팅 구성 |
| 4주차 | 네트워크 이중화 및 고가용성 구성 |
| 5주차 | 네트워크 보안 및 접근 제어 |
| 6주차 | 3-Tier 구조 한계 분석 및 Leaf-Spine 전환 |
| 7주차 | 네트워크 모니터링 및 장애 분석 |
| 8주차 | 데이터센터 네트워크 구조 완성 |
